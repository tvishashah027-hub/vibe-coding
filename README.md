# 🎓 CampusTrack — All College Events & Submissions Tracker

A clean, modern, and responsive web application built with **HTML5, Vanilla CSS3, and JavaScript (ES6+)** to track all college events, hackathons, academic submissions, workshops, fests, placement drives, and sports tournaments in one single hub.

---

## 🚀 Quick Start

Open [`index.html`](file:///c:/Users/ASUS/OneDrive/Desktop/vibe%20coding/index.html) in your browser:
- Simply double-click `index.html` in File Explorer, or
- Right-click and choose **Open with > Google Chrome / Microsoft Edge / Firefox**.

---

## ✨ Features

1. **⚡ Next Upcoming Event Highlight**:
   - Prominently showcases the next upcoming college event or deadline.
   - Large live countdown clock (`Days : Hours : Mins : Secs`) that updates every second in real time.
   - Quick one-click registration / submission portal link.

2. **🎪 All College Categories Covered**:
   - 📚 **Exams & Tests** (Midterms, End-Semester Finals, Quizzes)
   - 🏆 **Hackathons & Coding Contests** (HackSpark 2026, CodeClash)
   - 📝 **Assignments & Submissions** (OS Kernel Lab, Database Indexing Project)
   - 💡 **Workshops & Seminars** (AI Agents Hands-on Workshop)
   - 🎭 **Cultural & Fests** (Aura 2026 Annual Cultural Fest)
   - 💼 **Placement & Career** (Google & TCS Recruitment Drive)
   - ⚽ **Sports Tournaments** (Inter-Department Football Championship)

3. **🔍 Instant Search & Quick Category Filters**:
   - Filter by category with one click or search by event name, department, host club, or venue.
   - Interactive metric cards that filter the dashboard when clicked.

4. **⏱️ Real-Time Countdown on Every Event Card**:
   - Displays live time remaining (`in 2d 4h`, `in 6h 30m`), pulsing red when due in under 24 hours.

5. **📅 Export to Google / Apple Calendar**:
   - Export any single event or all college events as an `.ics` file with one click.

6. **💾 Local Storage Persistence**:
   - Everything is saved directly in your browser. Add, edit, or mark events as completed without losing data.
